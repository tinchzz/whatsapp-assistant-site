Política de privacidad

Última actualización: 6 de noviembre de 2026

Esta página describe el tratamiento de datos previsto en la implementación actual de Asistente personal (WhatsApp Assistant), un proyecto independiente en desarrollo y pruebas de uso personal. Su responsable es tinchzz.

Datos que procesa el asistente

  • Mensajes recibidos: identificador del mensaje, número o identificador del remitente, texto y fecha de recepción. Para mensajes que no son de texto, la implementación actual guarda una etiqueta del tipo de mensaje.
  • Menús y recordatorios: fechas, descripciones, destinatarios, horarios y configuración cargada por quien administra el proyecto.
  • Registros de envío: estado de cada intento de entrega y detalles técnicos asociados.
  • PDF cargados mediante la API de administración: se procesan en memoria para extraer texto; el archivo no se guarda por esa función. El texto puede guardarse posteriormente como menú mediante una acción administrativa.

Para qué se usan

Los datos se utilizan para probar la recepción de mensajes, organizar menús, programar recordatorios y diagnosticar el funcionamiento del proyecto. Las respuestas conversacionales automáticas todavía están en desarrollo. La implementación actual no integra un proveedor de inteligencia artificial.

WhatsApp y proveedores técnicos

La comunicación por WhatsApp utiliza la plataforma de Meta, que procesa información conforme a sus propias condiciones y políticas. Durante las pruebas puede utilizarse Cloudflare Tunnel para transportar eventos al servidor del proyecto. El almacenamiento del asistente depende del entorno configurado por su administrador.

Conservación y acceso

Los mensajes, menús y recordatorios se almacenan en la base de datos del proyecto. La versión actual no tiene un plazo de borrado automático; su eliminación requiere intervención del administrador. Desactivar un recordatorio impide su ejecución futura, pero no elimina por sí solo el registro almacenado.

Consulta y eliminación de datos

Para solicitar información o iniciar una solicitud de eliminación, contactá al responsable mediante una consulta en el repositorio. Indicá solamente que necesitás un canal privado para una solicitud de privacidad. El responsable deberá coordinar ese canal y verificar la solicitud antes de intervenir sobre los datos.

Las consultas de GitHub son públicas: no publiques números de teléfono, mensajes, documentos, credenciales ni otros datos personales. La solicitud no produce una eliminación automática.

Este sitio web

Estas páginas son informativas y no incluyen formularios, cookies propias ni herramientas de analítica. GitHub Pages, el proveedor de alojamiento, puede procesar datos técnicos de las visitas conforme a su declaración de privacidad.

Cambios en el proyecto

Esta información se actualizará si cambian las funciones o los proveedores utilizados. La página de inicio identifica las funciones disponibles y las que continúan en desarrollo.
