El proyecto

Pequeñas tareas.
Una ayuda concreta.

WhatsApp Assistant es un desarrollo independiente y experimental. Su objetivo es organizar información cotidiana desde un canal familiar.

01 / MENÚS

La comida, organizada.

La base actual permite guardar y consultar menús por fecha, y extraer texto de archivos PDF para revisión manual.

02 / RECORDATORIOS

Un lugar para tus pendientes.

Permite configurar recordatorios diarios o para una fecha. El envío está desactivado por defecto durante las pruebas.

03 / CONVERSACIÓN

El siguiente paso: el chat.

La recepción de mensajes está implementada. Las respuestas automáticas y la gestión conversacional todavía están en desarrollo.
